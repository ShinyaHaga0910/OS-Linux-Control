## Термины

Русская версия использует закрепившиеся русские технические термины. Соответствия записаны в колонке `ru` файла `terminology.csv`. Не переносить автоматически узбекское правило «оставлять IT-термины на английском».

| Понятие | Основной вариант | Уточнение |
| --- | --- | --- |
| operating system | операционная система (ОС) | При первом упоминании раскрыть сокращение. |
| kernel / user space | ядро / пространство пользователя | Не смешивать с учётной записью `root`. |
| directory / path | каталог / путь | Для учебника не чередовать «каталог» и «папка». |
| permission / authentication / authorization | права доступа / аутентификация / проверка прав доступа | Аутентификация отвечает на вопрос «кто?», проверка прав — «что разрешено?». |
| process / program / service / unit | процесс / программа / служба / юнит | Различать запущенный процесс, управляемую службу и конфигурационный юнит systemd. |
| socket / port / log | сокет / порт / журнал | `journalctl` показывает записи системного журнала. В контексте отдельного файла допустимо «файл журнала». |
| shell / terminal / command | командная оболочка / терминал / команда | `Bash` — имя конкретной оболочки. |
| primary / supplementary group | основная / дополнительная группа | Логины и имена групп не переводить. |
| public / private key | открытый / закрытый ключ | Не путать с паролем; содержимое реальных ключей в материалы не включать. |

`Linux`, `Ubuntu`, `Unix`, `Bash`, `systemd`, `SSH`, `SCP`, `AWS`, `EC2`, `CloudShell`, `HTTP`, `TCP`, `PID`, `UID`, `GID`, имена команд и пакетов остаются в исходной записи. Имена путей, файлов, пользователей, групп, служб, ключи конфигурации, порты, URL, ID проверок и строки, которые студент должен вводить буквально, также не переводить.

## Содержание и формат

- Сохранять порядок глав и разделов, кодовые блоки, задания, ответы, номера и идентичность рисунков.
- Объяснять термин простым русским предложением при первом использовании. Не подменять объяснение англицизмом.
- Не менять смысл команды или критерия проверки ради более гладкого текста.
- Подписи в 21 схеме переводить отдельно; историческую фотографию не менять.
- В заданиях ясно различать AWS CloudShell (локальная сторона SSH/SCP) и Ubuntu EC2 (удалённая сторона).
- В PDF использовать шрифт с кириллицей; проверять переносы, таблицы и отсутствие японского текста.
