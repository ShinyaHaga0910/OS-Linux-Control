# 本書のまとめ

[日本語](../../ja/textbook/afterword.md) · [Русский](../../ru/textbook/afterword.md) · [O‘zbekcha](../../uz/textbook/afterword.md)

コンピューター上のプログラムは、OSが提供する機能を利用して動く。Linuxを操作するときは、コマンドの名前だけでなく、その操作がファイル、ユーザー、プロセス、通信のどれに関わるかを考えると、結果を理解しやすい。

設定ファイルが存在すること、サービスのプロセスが動いていること、ネットワークから期待した応答を得られることは、それぞれ異なる状態である。ある一つの状態が正しくても、ほかの状態が正しいとは限らない。ファイルの所有者やアクセス権、サービスの実行ユーザー、待受ソケット、ログを区別して読むことが大切である。

後続の授業では、Nginx、BIND 9、PostgreSQLなど、用途の異なるソフトウェアを扱う。それぞれの設定方法は異なるが、「どのユーザーで動くか」「どのファイルを使うか」「どこで通信を受けるか」「動作をどこで確認できるか」という問いは共通して使える。本書で学んだOSの基本概念を、新しいシステムを理解するための土台にしてほしい。

コマンドの綴りやオプションを読み直したい場合は、巻末の参照資料として用意した[用語集・コマンド早見表](../reference.md)の「コマンドの読み方」「findを段階的に読む」「grepでファイルの中の行を探す」「tailで末尾の行を読む」を参照してほしい。`id -un`のuser・nameの対応や、検索開始位置・条件・表示を分けた読み方を、短い実行例で説明している。
