# Русская версия

[日本語](../ja/README.md) · [Русский](README.md) · [O‘zbekcha](../uz/README.md)

Статус: полный черновой перевод ChatGPT. Проверка структуры и PDF выполнена; редактура русскоязычным преподавателем и испытание со студентами ещё не проведены. Это не утверждённое учебное издание.

Упражнения P0–P6, задания M1–M7 и справочник синхронизированы по содержанию с действующим японским источником. Перевод остаётся черновиком ChatGPT до проверки преподавателем-носителем языка.

Текущий источник перевода — японские файлы `docs/ja/`. Русские устоявшиеся IT-термины выбраны по [правилам терминологии](../../localization/russian-style-guide.md) и внесены в колонку `ru` [общего глоссария](../../localization/terminology.csv). Команды, пути, имена, номера заданий и строки, которые требуется вводить буквально, сохранены.
