# 学生の初回セットアップ・採点システム登録

AWS Academyへの登録後、教員が配布したコマンドを実行し、自分専用の進捗ダッシュボードを開くまでの手順書です。PDFは作成しません。

| 言語 | 手順書 |
| --- | --- |
| 日本語 | [初回セットアップ](student-registration.ja.md) |
| ロシア語 | [Первоначальная настройка](student-registration.ru.md) |
| ウズベク語 | [Dastlabki sozlash](student-registration.uz.md) |

完了条件は、セットアップ・メールの紐づけが成功し、自分のダッシュボードが表示されることです。P0の演習・提出は次の段階です。

登録処理とコマンドは現行スクリプトと照合しています。AWS上での新規構築と全演習の通し受入試験は未完了です。翻訳の最終確認は教員が行います。
